Instalar pyenv en windows desde powershell


Copia, pega el siguiente comando y presiona Enter:powershell

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser


git clone https://github.com/pyenv-win/pyenv-win.git "$HOME\.pyenv"

Configurar las Variables de Entorno

Presiona la tecla Windows, escribe Variables de entorno y selecciona Editar las variables de entorno del sistema.

En la sección Variables del sistema, busca la variable llamada Path y haz clic en Editar.
C:\Users\TU_USUARIO\.pyenv\pyenv-win\bin
